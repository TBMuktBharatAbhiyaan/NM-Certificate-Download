# Nikshay Mitra Certificate Generator

A web application to generate and download certificates for Nikshay Mitra participants with ID validation.

## Features

- ✅ **ID Validation**: Validates Nikshay Mitra ID format (12 characters: M + 11 digits)
- ✅ **Real-time Preview**: See certificate before downloading
- ✅ **PDF Generation**: High-quality PDF certificates with proper positioning
- ✅ **Responsive Design**: Works on desktop and mobile devices
- ✅ **Error Handling**: Clear validation messages with red warning for invalid IDs

## ID Format Requirements

The Nikshay Mitra ID must follow these rules:
- **Length**: Exactly 12 characters
- **First Character**: Must be 'M'
- **Rest 11 Characters**: Must be digits (0-9)
- **Example**: M12345678901
